# 外部參考資料規範

[English](reference-policy.en.md)

本文件整理已接受的 credibility tier 與引用原則，作為共用定義；整理後的文件仍待審閱。

## Credibility tier

依具體證據及其支持的主張分級，不只看網站或組織名稱。

| Tier | 來源範例 | 使用方式 |
| --- | --- | --- |
| T1 | 適用版本官方文件、release notes、原始碼、正式標準 | 技術行為與限制的主要依據，仍須符合版本、設定與證據範圍。 |
| T2 | 維護者 issue／PR、一手設計提案、附環境與方法的工程報告 | 支持分析及背景；提案或個案不代表正式支援能力。 |
| T3 | 有引用、版本及可重現方法的第三方文章或教學 | 補充解釋與探索；重要主張由適用 T1 或相關一手驗證交叉確認。 |
| T4 | 無來源主張、無佐證論壇回答、AI 摘要 | 僅作搜尋／驗證線索，不作為規格的唯一依據。 |

## 適用性與驗證

- 權威性、適用性與驗證狀態分開判斷。檢查版本、日期、設定、workload、部署模式及是否為已發布行為。
- 不假定 `/latest/` 適用於候選 Doris 版本；優先找對應版本。候選版本本身也不代表已驗證發布或相容性。
- 官方 benchmark 或行銷說法不是通用效能保證；原始碼觀察不必然構成正式支援的公開介面承諾。
- Apache Doris 上游能力不等於本服務提供的能力或保證；服務範圍與開放狀態須另行確認。
- 來源衝突時記錄主張及版本／條件差異；不能平均說法或默默選擇方便的來源。
- 找不到或無法存取來源時標示未驗證與所需檢查，不虛構引文、引用、存取日期或驗證結果。
- 目前沒有來源白名單／黑名單；優先採用適用的一手資料。

## 引用紀錄

在重要主張附近標示 reference ID，於同文件的參考資料章節記錄下列欄位。雙語使用相同 ID 與證據，不因翻譯重新分級。

| 欄位 | 記錄方式 |
| --- | --- |
| ID、標題、出處 | 穩定 ID、來源標題、URL 或 repository 路徑。 |
| Tier | 外部來源使用 T1–T4。 |
| 版本／revision、發布日期 | 記錄已知資訊；未知標為 `unknown`。 |
| 存取日期 | 真正存取的日期；未存取則如實標示。 |
| 支持主張、適用條件 | 說明來源支持什麼，以及限制。 |
| 本地驗證 | 方法、結果與證據位置，或 `not verified`。 |

使用者陳述與已核准內部決策是決策來源，不自動分為 T1。記錄確認內容及可用出處，不宣稱讀過無法取得的 Pipeline 文件。只採用使用者確認適合記錄的資訊。

## 待釐清事項

- 版本相關引用須待 Doris 版本選定後逐項確認；目前不建立虛構的產品引用。
